学习记录这个专栏，用来放笔记、练习过程和踩过的坑。今天先记两个小问题。

## 一、字符串和数字的来回转换

用 C++ 处理一串数字时，把每一位拆出来是最常见的操作：

```cpp
for (int i = 0; i < s.size(); i++) {
    int digit = s[i] - '0';   // 字符转数字
}
```

反过来，数字转字符就加回 `'0'`。这个转换在模拟题里出现频率很高，值得单独记一笔。

## 二、二维数组存间隔点

有些题需要判断两个点之间有没有其它点，暴力检查容易写错。把"两点之间还藏着哪些点"预先存进一个二维数组，用的时候直接查，代码会干净很多。

> 先把问题想清楚，再动手写。急着敲键盘的时候，往往要返工。

## 小结

- 字符和数字的转换，靠 ASCII 差值
- 能预处理的关系，别每次现算
- 写完先自己造几组边界数据试一下
