这个小站用的是 [Astro](https://astro.build)，一个静态站点生成器。

## 为什么选它

- 写文章就是写 Markdown，一个文件一篇
- 构建出来是纯静态的 HTML，扔到哪都能跑
- 默认不带 JavaScript，打开快

## 结构大概是这样

| 位置 | 放什么 |
| --- | --- |
| `src/content/blog/` | 文章，一个 `.md` 一篇 |
| `src/pages/` | 页面路由 |
| `src/layouts/` | 页面外壳 |
| `src/styles/` | 样式 |

## 发布

代码推到 GitHub，仓库里配了一个 Actions 工作流，推上去自动构建，然后发布到 GitHub Pages。

改完文章只要：

```bash
git add .
git commit -m "新增一篇文章"
git push
```

等一两分钟，线上就更新了。
